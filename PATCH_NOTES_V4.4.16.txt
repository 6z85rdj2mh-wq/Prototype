FREE GUIDES CMS-READY

BASE
- Parte dalla V4.4.15 stabile.
- Non modifica la struttura visiva approvata delle Guide gratuite.
- Preserva Guide Premium, Tornei, homepage, lingua e commenti.

ARCHITETTURA GUIDE GRATUITE
- `js/data/free-guides.js` è ora un archivio CMS-ready versione 4.4.16.
- Le quattro guide esistenti sono record `published`.
- Aggiunti stati: draft, published, archived, trash.
- Il sito pubblico usa esclusivamente `getPublishedGuides()`.
- Il dettaglio riconosce sia ID sia slug.
- URL pubblico generato automaticamente: `guida/?id={slug}`.

FUTURA ADMIN
- Template vuoto in `admin/free-guides/free-guide-template.json`.
- Contratto UI/dati in `admin/free-guides/free-guides-admin-contract.json`.
- Workflow in `admin/free-guides/ADMIN_WORKFLOW.md`.
- API disponibili: crea, duplica, valida, pubblica, archivia, cestino, ripristina ed elimina definitivamente.
- Le bozze possono essere incomplete; una guida pubblicata deve avere Leader, titolo e formato.
- ID e slug devono essere univoci.

MODULI

- Moduli opzionali fino a 5 istanze.
- Sezioni con carte fino a 5 elementi.
- Moduli attivabili, disattivabili e riordinabili.
